# Detecting Active Directory Credential Attacks

## Overview

This repository documents my learning and detection analysis
while studying Active Directory credential attacks through a
TryHackMe.

The main focus is understanding how credential attacks against
Active Directory can be detected from a defensive security
perspective.

## Objectives

- Understand common Active Directory credential attacks
- Identify relevant Windows security events
- Analyze attacker behavior from logs
- Map suspicious activity to MITRE ATT&CK
- Develop detection ideas for SOC environments
- Document investigation methodology

## Topics

- Active Directory authentication
- Credential attacks
- Kerberoasting
- NTLM authentication
- Windows Event Logs
- Detection Engineering
- MITRE ATT&CK
- SOC investigation
